# Imagens das cartas de desenvolvimento

As cinco imagens adicionadas em `cartas base` foram copiadas para `public/cards/development/`. A interface usa os arquivos abaixo na mão, na animação e na revelação ampliada:

| Carta | Arquivo |
| --- | --- |
| Cavaleiro | `knight.jpg` |
| Construção de estradas | `road_building.jpg` |
| Ano de abundância | `year_plenty.jpg` |
| Monopólio | `monopoly.jpg` |
| Ponto de vitória | `victory.jpg` |
| Verso da carta | `back.jpg` |

Os JPGs originais têm 1376 × 768 pixels, com a carta centralizada. O CSS exibe apenas a área da carta, sem o fundo branco externo; os arquivos de origem permanecem intactos. A descrição acessível abaixo da carta ampliada continua como texto da interface.

O verso fornecido tem 1093 × 976 pixels e aparece no monte de desenvolvimento, no trajeto da carta comprada e nas cartas ocultas dos outros jogadores. O CSS recorta a carta central, escondendo o fundo de madeira da imagem original.
